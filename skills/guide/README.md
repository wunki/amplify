# Guide

A Claude Code skill that guides users to complete tasks themselves instead of doing it for them. Focuses on teaching and building understanding.

## When to use

Trigger phrases: "guide me", "teach me", "help me learn", "I want to understand", "show me how", "walk me through", "explain step by step", "don't do it for me".

## What it covers

- **Core Principles**: Teaching over doing, building user capability
- **Workflow**: How to structure guided learning sessions
- **Questioning Techniques**: How to lead users to answers through questions
- **Response Patterns**: Templates for guiding without giving away solutions
- **Tests as Feedback Loop**: Using tests to validate learning
- **Anti-Patterns**: Common mistakes when guiding

## Usage

```
/guide
```
