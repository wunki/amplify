# Frontend Design

A Claude Code skill that creates distinctive, production-grade frontend interfaces with high design quality. Avoids generic AI aesthetics.

## When to use

When building web components, pages, artifacts, posters, or applications: websites, landing pages, dashboards, React components, HTML/CSS layouts, or when styling/beautifying any web UI.

## What it covers

- **Design Thinking**: How to approach interface design with intention
- **Frontend Aesthetics Guidelines**: Principles for creating polished, distinctive UI that doesn't look AI-generated

## Usage

```
/frontend-design
```
