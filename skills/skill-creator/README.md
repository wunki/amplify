# Skill Creator

A Claude Code skill for creating or updating skills that extend Claude's capabilities. Handles SKILL.md files, frontmatter, references, scripts, and skill structure.

## When to use

When asked to "create a skill", "make a new skill", "write a skill for", "update this skill", or when working with SKILL.md files and skill structure.

## What it covers

- **About Skills**: What skills are and how they work in Claude Code
- **Core Principles**: Design philosophy for effective skills
- **Quick Start**: Creating a minimal skill from scratch
- **Advanced Features**: References, scripts, output patterns, workflows
- **Creating/Editing Documents**: Working with skill files
- **Skill Creation Process**: End-to-end workflow for building a skill

## Files

- `SKILL.md` - Main skill definition
- `references/workflows.md` - Skill workflow patterns
- `references/output-patterns.md` - How skills produce output
- `scripts/init_skill.py` - Initialize a new skill directory
- `scripts/package_skill.py` - Package a skill for distribution
- `scripts/quick_validate.py` - Validate skill structure

## Usage

```
/skill-creator
```
