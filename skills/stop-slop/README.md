# Stop Slop

A Claude Code skill that removes AI writing patterns from prose. Eliminates predictable AI tells to make text sound human.

## When to use

When drafting, editing, or reviewing text to eliminate AI-sounding patterns.

## What it covers

- **Core Rules**: What makes writing sound like AI and how to fix it
- **Quick Checks**: Fast validation for common AI patterns
- **Scoring**: How to rate prose for AI-ness
- **Examples**: Before/after transformations

## Files

- `SKILL.md` - Main skill definition
- `references/examples.md` - Example rewrites
- `references/structures.md` - Structural patterns to avoid
- `references/phrases.md` - Specific phrases and words to eliminate

## Usage

```
/stop-slop
```
