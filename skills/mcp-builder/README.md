# MCP Builder

A Claude Code skill for creating high-quality MCP (Model Context Protocol) servers that enable LLMs to interact with external services through well-designed tools.

## When to use

When building MCP servers to integrate external APIs or services, whether in Python (FastMCP) or Node/TypeScript (MCP SDK).

## What it covers

- **Overview**: What MCP servers are and how they work
- **High-Level Workflow**: End-to-end process for building an MCP server
- **Documentation Library**: Reference materials for both Python and Node implementations

## Files

- `SKILL.md` - Main skill definition
- `reference/mcp_best_practices.md` - MCP design best practices
- `reference/python_mcp_server.md` - Python/FastMCP server guide
- `reference/node_mcp_server.md` - Node/TypeScript server guide
- `reference/evaluation.md` - How to evaluate MCP server quality
- `scripts/evaluation.py` - Evaluation script
- `scripts/connections.py` - Connection testing utilities

## Usage

```
/mcp-builder
```
