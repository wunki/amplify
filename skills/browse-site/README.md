# Browse Site

A Claude Code skill for browser automation using the agent-browser CLI. Navigate websites, fill forms, take screenshots, extract data, and automate browser workflows.

## When to use

When you need to interact with a website: navigate to URLs, click elements, fill out forms, take screenshots, scrape data, or test web apps.

## What it covers

- **Installation**: Setting up agent-browser
- **Quick Start**: Basic navigation and interaction
- **Workflow**: How to approach browser automation tasks
- **Common Commands**: Navigation, clicking, typing, screenshots
- **Sessions**: Managing persistent browser sessions
- **Snapshot Options**: Capturing page state

## Usage

```
/browse-site
```

Trigger phrases: "go to [url]", "click on", "fill out the form", "take a screenshot", "scrape", "automate", "test the website", "log into".
