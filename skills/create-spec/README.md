# Create Spec

A Claude Code skill that creates or updates a SPEC.md document from requirements, notes, or interview output. Structures information into a consistent specification format.

## When to use

When asked to "create a spec", "write a spec", "turn this into a spec", "spec template", or when structuring requirements into a specification document.

## What it covers

- **When to Use**: Situations that call for a spec
- **Workflow**: How to gather and structure requirements
- **Spec Quality Checklist**: Validation criteria for completeness
- **Example Usage**: Real-world spec patterns
- **Anti-patterns**: Common spec mistakes to avoid

## Files

- `SKILL.md` - Main skill definition
- `references/spec-template.md` - Reusable spec template

## Usage

```
/create-spec
```

Pairs well with the `interview` skill for requirements gathering.
