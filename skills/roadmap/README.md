# Roadmap

A Claude Code skill that creates a ROADMAP.md document for open source projects. Analyzes the codebase, defines vision and milestones, and organizes work into short/medium/long term goals.

## When to use

Trigger phrases: "create a roadmap", "generate roadmap", "write a ROADMAP.md", "project roadmap", or when communicating project direction to contributors.

## What it covers

- **Process**: How to analyze a codebase and define direction
- **Template**: Standardized ROADMAP.md structure
- **Sections**: Current status, vision, how to contribute, timeline, out of scope, completed work
- **Guidelines**: Writing effective roadmap entries that attract contributors

## Usage

```
/roadmap
```
