# Write Test

A Claude Code skill that writes meaningful tests using coverage as a guide to find untested user-facing behavior. Focuses on one test per iteration, prioritizing real user workflows over implementation details.

## When to use

When asked to "write tests", "add test coverage", "increase coverage", "test this feature", or when coverage reports show gaps.

## What it covers

- **What Makes a Great Test**: Philosophy for writing tests that matter
- **Process**: Coverage-guided test writing, one test at a time
- **Guidelines**: Test behavior not implementation, use real code paths
- **Coverage Commands**: How to run and interpret coverage reports
- **When to Stop**: Knowing when coverage is sufficient

## Usage

```
/write-test
```
