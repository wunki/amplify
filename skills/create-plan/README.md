# Create Plan

A Claude Code skill that creates structured implementation plans for coding tasks. Interviews to extract intent, thinks deeply before planning, and writes a plan file.

## When to use

When asked to "create a plan", "make a plan for", "plan out", "help me plan", or when a task needs a structured approach before implementation.

## What it covers

- **Workflow**: Interview, research, plan, confirm
- **Phases**: How planning progresses from requirements to actionable tasks
- **Plan Format**: Standardized structure with scope, success criteria, assumptions, and action items
- **Plan Template**: Ready-to-use template for consistent plans
- **Checklist Guidance**: Quality checks before finalizing

## Output

Writes a `PLAN.md` file that can be executed step-by-step with the `execute-plan` skill.

## Usage

```
/create-plan
```
